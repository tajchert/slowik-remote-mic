# macos/Receiver — Slowik Mac receiver (agent guide)

Receives the phone's UDP audio (docs/PROTOCOL.md), de-jitters it, compensates clock drift, runs a voice DSP chain
and plays into the "Slowik Mic" virtual device (UID `SlowikMic_UID`, built in `macos/Driver/`).

## Layout
- `Package.swift` — SwiftPM package (tools 5.9, Swift 5 language mode, C++17). Products: `SlowikEngine`, `SlowikCore`, `slowik-rx`.
- `Sources/SlowikEngine/` — C++17 engine, **plain C API** in `include/slowik_engine.h` (no Swift/C++ interop needed).
  - `protocol.cpp` — byte-exact AUDIO parse (PCM16/PCM24), CONTROL/AUDIO builders.
  - `engine.cpp` — SPSC queue, jitter buffer ring, concealment, windowed-sinc resampler, PI drift control, stats.
- `Sources/SlowikSim/` — deterministic network/clock simulator (C++) used only by tests.
- `Sources/SlowikCore/` — Swift glue shared by app + CLI: `UDPReceiver` (BSD socket thread, CONTROL 5 Hz, plus
  `BonjourAdvertiser`, `localIPv4Addresses`), `AudioOutput` (AVAudioEngine chain + device attach), `AudioDevices`
  (CoreAudio helpers), `ReceiverService`, `ClockRenderer` (host-clock render for headless use), `WavWriter`.
- `Sources/slowik-rx/main.swift` — headless CLI / integration harness.
- `Tests/SlowikEngineTests/` — Swift Testing tests over the C API + simulator.
- `App/` — SwiftUI `MenuBarExtra` app. `project.yml` (XcodeGen, committed), `Info.plist` (generated by XcodeGen from
  `project.yml`, committed), `Sources/`. `*.xcodeproj` and `App/build/` are gitignored.
- `scripts/integration.sh`, `scripts/wavcheck.py` — end-to-end check with `tools/slowik_sim.py` (needs numpy).

## Commands (run from `macos/Receiver/`)
- Engine tests (~1 s run, 13 tests incl. a 10-min simulated ±150 ppm run): `swift test 2>&1 | grep -E "✘|Test run"`
- CLI build: `swift build -c release --product slowik-rx` → `$(swift build -c release --show-bin-path)/slowik-rx --help`
- Integration (≈40 s): `scripts/integration.sh 30`
- App: `cd App && xcodegen generate && xcodebuild -project SlowikReceiverApp.xcodeproj -scheme SlowikReceiver -configuration Debug -derivedDataPath build/DerivedData build 2>&1 | grep -E "error:|BUILD"`
  → `App/build/DerivedData/Build/Products/Debug/Slowik Receiver.app`
- Don't make audible noise when testing: use `slowik_sim.py send --amp 0.001` with `slowik-rx --play default --trim -24`.

## Threading rules (do not break)
- `slowik_engine_push_packet`: exactly ONE network thread (SPSC producer). Parsing/PCM conversion happens here.
- `slowik_engine_render`: exactly ONE consumer at a time — either the AVAudioEngine source-node render block, or a
  `ClockRenderer` (CLI, or `AudioOutput`'s idle renderer while no device plays). `AudioOutput` stops one before
  starting the other. Never call render from two threads.
- Render path: no locks, allocation, syscalls, logging or Swift object allocation. All jitter-buffer state is owned by
  the render thread; cross-thread data = SPSC queue + relaxed atomics (stats, live, mute, output latency).
- `get_stats`, `set_live/mute`, `build_control` are safe from any thread.

## Engine design (summary; details in comments of engine.cpp)
- Ring of 128 frames (640 ms) keyed by frame index = (sample_index − align)/240. Redundant copies dedupe by tag;
  duplicate packets detected by seq window; reordering is free.
- Reader per frame: present → play; missing but later data present → conceal (mirror-repeat of last 5 ms with
  15 ms exponential decay) and skip; nothing newer → **stall** (conceal without advancing; buffer grows). A stall that
  resolves with the frame = underrun (+2 ms target bump); resolved by newer data = loss. 2 ms crossfade back to audio.
- No new frame for 150 ms → LINK_LOST, 5 ms fade to silence; next packet → resync. Resync also on sample_index
  jumping back > 200 ms (sender restart), misalignment, or data beyond ring capacity.
- Target = p99 − mean of first-arrival transit (10 s window) + 2.5 ms + 2·block + resampler + 3 ms margin, clamped
  10–80 ms. Grows instantly; shrinks (peak-hold 10 s, 2 ms hysteresis) by playing 100 ppm fast (250 ppm below −40 dBFS).
- Resampler: 16-tap Kaiser windowed sinc, 256 phases (linear interp). Ratio = 1 + PI(fill − target), ±200 ppm
  steady; 10 s catch-up after resync (5× Kp, ±2000 ppm). Integrator gated (|e| < 2 ms, anti-windup).
- Drift sign: `drift_ppm > 0` = phone clock faster than output clock. `slowik_sim.py --ppm 150` (slower sender) → ≈ −150.
